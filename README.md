This repository represents a workflow to calculate the population branch statistic between three populations (which is the minimum amount of populations required to calculate a population branch statistic). This pipeline is based on the 2009 study _The Origins of Lactase Persistence in Europe_. Thus, it contains code meant to specifically look at the lactase persistence region on chromosome 2 (between position 135000000 and 136500000). However, this code can easily be used to look at other regions and explore other questions related to population genetics.  

First, in 01_downloadData, this code downloads data, and relies on SRA data (from the NIH). This requires a metadata file. It also downloads a reference genome from the NIH.  

Next, in 02_qc, it runs fastqc and multiqc on the data. Next, it runs trimmomatic to trim the files. It then runs fastqc and multiqc again on the trimmed files. 02_qc was originally done on two populations (Yoruba and England), while a partner ran similar code on the third population. This folder would have to be edited slightly to run directly on three populations for the specific populations looked at. For example, the in-directories would have to be renamed and correctly defined for the specific in-directory population(s) that one would want to look at. However, this is a minor edit. 

In 03_alignment, an index of the genome is created using bwa-mem2. Next, in 02_EnglandbwaAlign.sh and 02_YorubabwaAlign.sh, the trimmed fastqc files are aligned to the reference genome. Again, the in-directories would have to be renamed and correctly defined for the specific in-directory population(s) that one would want to look at. However, this is a minor edit. This step produces bam files from the fastq files. 

In 04_alignmentQC, samstats is run on the outputted bam files. Next, coverage is calculated, and bedtools is run. A gene map index and a gene map is made. 

Afterwards, in 05_variantcalling, variants are called in parallel using freebayes. The bam files from 03_alignment are used to create a singular vcf file. 06_filteringAnnotating has a script that does very basic filtering on this data. This is because this project was originally done using low coverage whole genome sequencing data. It can be adapted for more stringent filtering for higher coverage data. 

Lastly, in 07_PopulationBranchStatistic, the data from this outputted vcf file is loaded into R. Before the data can be loaded, the filtered vcf file will have to be used to create frq files (one for each population). Each file can then be loaded into R. Plot1.R looks at the first 11 chromosomes, while Plot2.R looks at the next 12-22. These codes calculate the population branch statistic from the frq tables, and outputs a Manhattan plot (Plot1.R does this for chromosomes 1-11, while Plot1.R does it for 12-22). Both codes also output a short list of the top outliers, with a threshold of 0.99 for outliers. Plot1.R should highlight the lactase persistent region of the Manhattan plot, which likely forms larger population branch statistic values than the majority of the plot. Plot1.R also outputs a list of the outliers specifically in that region. Again, these R codes can easily be adapted to look at other regions in the Manhattan plot.
